## Fork Guidelines

If you fork ReadmeCraft:

1. **Rename your fork** — e.g., `my-readme-tool`, `custom-readme-studio`
2. **Remove/replace all trademarks** — logo, name, references in UI
3. **Add clear attribution** in README:
   ```markdown
   Based on [ReadmeCraft](https://github.com/ErBharatMalhotra/readmecraft) by Bharat Malhotra.
   This fork is not affiliated with, endorsed by, or connected to ReadmeCraft.
   ```
4. **Comply with AGPL-3.0** — if hosted publicly, provide source
