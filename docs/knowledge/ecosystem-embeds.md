# Ecosystem Embeds — GitHolo & GitChronicle Integration

> Technical reference for BharatDN ecosystem cross-pollination widgets.

---

## 🎯 Overview

Every README generated by ReadmeCraft includes opt-in embed snippets for two sister projects:
1. **GitHolo** — 3D WebGL Holographic GitHub Cards
2. **GitChronicle** — Live Percentile Cadence & Velocity Badges

These are the primary growth engine — each generated README becomes a distribution channel.

---

## 🌌 GitHolo 3D Card

### Product
**GitHolo** — Interactive 3D holographic cards for GitHub profiles and repositories. WebGL shaders, real-time data, shareable as images.

### Endpoints
| Purpose | URL Pattern | Parameters |
|---------|-------------|------------|
| **OG Image (Dynamic)** | `https://githolo.vercel.app/api/og/{username}` | `username` (GitHub handle) |
| **Landing Page** | `https://githolo.bharatdn.com` | — |
| **Repo Card OG** | `https://githolo.vercel.app/api/og/{owner}/{repo}` | `owner`, `repo` |

### Embed Snippet (Profile Mode)
```markdown
[![GitHolo 3D Card](https://githolo.vercel.app/api/og/ErBharatMalhotra)](https://githolo.bharatdn.com)
```

### Embed Snippet (Project Mode)
```markdown
[![GitHolo 3D Card](https://githolo.vercel.app/api/og/ErBharatMalhotra/readmecraft)](https://githolo.bharatdn.com)
```

### Markdown Structure
```markdown
[![Alt Text](OG_IMAGE_URL)](LANDING_PAGE_URL)
```
- **Alt Text:** "GitHolo 3D Card" (accessibility)
- **Image:** Dynamic OG endpoint — generates fresh card on each request
- **Link:** Landing page — drives traffic to GitHolo

### Implementation in ReadmeCraft
```typescript
// Profile generators (lib/generators.ts)
const username = data.username;
const gitHoloSnippet = `[![GitHolo 3D Card](https://githolo.vercel.app/api/og/${username})](https://githolo.bharatdn.com)`;

// Project generators
const gitHoloSnippet = `[![GitHolo 3D Card](https://githolo.vercel.app/api/og/${owner}/${repo})](https://githolo.bharatdn.com)`;

// Quick-insert in Editor Toolbar (PaneMarkdownEditor.tsx)
insertSnippet(`[![GitHolo 3D Card](https://githolo.vercel.app/api/og/${activeUsername})](https://githolo.bharatdn.com)\n`);

// Quick-copy in Export Toolbar (ExportToolbar.tsx)
const snippet = `[![GitHolo 3D Card](https://githolo.vercel.app/api/og/${activeUsername})](https://githolo.bharatdn.com)`;
await navigator.clipboard.writeText(snippet);
```

### Toggle Control
Stored in `ProfileData.gitHoloEnabled` / `ProjectData.gitHoloEnabled` — persisted in localStorage.

## 📈 GitChronicle Cadence Badge

### Product
**GitChronicle** — Live developer percentile badges showing commit velocity, cadence, and consistency metrics. Real-time SVG badges.

### Endpoints
| Purpose | URL Pattern | Parameters |
|---------|-------------|------------|
| **Badge SVG (Dynamic)** | `https://gitchronicle-wheat.vercel.app/badge/{username}.svg` | `username` (GitHub handle) |
| **Landing Page** | `https://gitchronicle.bharatdn.com` | — |
| **Repo Badge** | `https://gitchronicle-wheat.vercel.app/badge/{owner}/{repo}.svg` | `owner`, `repo` |

### Embed Snippet (Profile Mode)
```markdown
[![GitChronicle Cadence](https://gitchronicle-wheat.vercel.app/badge/ErBharatMalhotra.svg)](https://gitchronicle.bharatdn.com)
```

### Embed Snippet (Project Mode)
```markdown
[![GitChronicle Cadence](https://gitchronicle-wheat.vercel.app/badge/ErBharatMalhotra/readmecraft.svg)](https://gitchronicle.bharatdn.com)
```

### Markdown Structure
```markdown
[![Alt Text](BADGE_SVG_URL)](LANDING_PAGE_URL)
```
- **Alt Text:** "GitChronicle Cadence" (accessibility)
- **Image:** Dynamic SVG badge — updates automatically
- **Link:** Landing page — drives traffic to GitChronicle

### Badge Variants (Query Parameters)
```markdown
# Default (cadence percentile)
https://gitchronicle-wheat.vercel.app/badge/{username}.svg

# Custom style

https://gitchronicle-wheat.vercel.app/badge/{username}.svg?metric=consistency
https://gitchronicle-wheat.vercel.app/badge/{username}.svg?metric=streak
```


### GitHub README Sanitization Check
GitHub's markdown sanitizer **allows**:
- ✅ Standard markdown images: `![alt](url)`
- ✅ Linked images: `[![alt](url)](link)`
- ✅ HTTPS image URLs
- ✅ SVG and PNG formats

GitHub's markdown sanitizer **strips**:
- ❌ `<script>` tags
- ❌ `<iframe>` tags
- ❌ `onload`, `onerror` handlers
- ❌ `javascript:` URLs

**Our snippets are safe** — pure markdown images with HTTPS URLs.
